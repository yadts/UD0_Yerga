## 1. Introducción

La **Inteligencia Artificial (IA)** se refiere a la simulación de la inteligencia humana en máquinas. Hoy en día, el uso de *Modelos de Lenguaje Grande* (LLMs) permite interactuar en lenguaje natural y generar código o texto formateado como **Markdown**.

Conceptos clave a recordar:
+ **Prompting:** La técnica de redactar instrucciones efectivas.
+ **Tokens:** Las unidades básicas de procesamiento en un LLM.
+ **Markdown:** Un lenguaje de marcado ligero para dar formato a un texto.

## 3. Ejemplo de Código en Python

Para conectarse a una API de IA en Python, se suele utilizar un patrón como el siguiente:

```python
import os

def saludar_ia(nombre_usuario):
    # Simulacion de respuesta de un modelo
    mensaje = f"Hola {nombre_usuario}, ¡bienvenido al módulo de IA!"
    return mensaje

print (saludar_ia("Estudiante"))
```
